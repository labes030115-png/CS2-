# CSQAQ 数据源能力报告

## 当前结论

截至 2026-08-04，本分支只完成自动化 Mock 测试和 Windows 本地探测工具。

所有真实接口能力：**未验证**。

本报告没有使用真实 Token，没有调用真实 CSQAQ 接口，也没有保存真实原始响应。Mock 测试不能证明官方接口实际支持某项能力，只能证明项目代码在合成响应下的预期行为。

## Mock 测试已经证明的代码行为

- 领域模型只接受 `lowest_listing`。
- 适配器只把合成响应中的悠悠最低在售价字段转换为当前价格。
- 合成响应中的 Steam 和其他平台价格不会进入返回对象。
- 空值、零值、负值和失败项目不会生成价格记录。
- 合成的 Token、IP 白名单、限流和网络错误会被分类为安全错误类型。
- CLI 不接受命令行 Token，状态命令不显示 Token，错误输出不包含服务器异常正文。
- 凭据层只允许 Windows Credential Manager；非 Windows 或非 WinVault 后端会被拒绝，不使用明文文件回退。

以上均为项目代码行为，不是官方接口能力结论。

## 脱敏合成样例

仓库中的 `research/samples/csqaq_current_price_redacted.json` 是人工合成测试夹具，并带有：

```json
{
  "synthetic": true,
  "contains_real_response": false,
  "metric": "lowest_listing"
}
```

该文件不包含真实 Token、Cookie、请求头、完整请求 URL、真实价格或真实原始响应。

## 当前可以承诺

- 提供 Windows 本地安全探测命令。
- Token 通过隐藏交互输入并交由 Windows Credential Manager 保存。
- 禁止命令行 Token；非 Windows 不提供文件凭据回退。
- 探测结果采用白名单字段，只输出 `lowest_listing` 相关脱敏信息。
- Mock 测试覆盖最低在售价解析、Steam 隔离和安全错误分类。

## 当前不能承诺

- 普通 Token 一定能取得当前悠悠价格。
- 任一枪皮、武器箱、刀具或手套一定有价格覆盖。
- 任意历史起点、固定历史粒度、指定起止时间或关机缺口回补。
- 企业接口、全量目录、高频批量或稳定限流阈值。
- CSQAQ 返回的名称、币种、时间戳和平台字段与 Mock 完全一致。
- 外部平台价格可以作为悠悠主价格或参与悠悠指标计算。

## 后续真实验证规则

真实探测只能由用户在 Windows 本机执行。测试完成前，未知能力只能标记为：

- 未验证
- 权限不足
- 不支持
- 数据不足

不得根据 Mock、官方文档示例或推测把未知能力写成“支持”。
