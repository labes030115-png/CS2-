- 测试日期：2026-08-03
- 运行环境：Windows 本地开发环境

## 权限与错误证据

- 企业合作接口：未调用，不能声明可用。
- 普通接口：绑定实际出口 IP 后可用。
- 白名单：绑定前实际返回 HTTP 401、业务码 401。
- 绑定操作：经用户批准后返回 HTTP 200、业务码 200。
- 当前价格探测：绑定后一次请求返回 3/3 个悠悠价格。
- 文档频率限制：单 IP 每秒 1 次；当前适配器按实例执行一秒间隔。
- 文档单次上限：最多 50 个 `marketHashName`；本次实际请求 3 个。

## 数据质量

- 名称映射：三个标准 `marketHashName` 均精确返回。
- 缺失对象：本次没有。
- 币种：适配器按悠悠人民币价格记录为 CNY；该批量响应本身没有独立币种字段。
- 时间戳：批量响应没有独立报价时间，`checked_at_utc` 是本地成功抓取时间。
- 原始更新粒度：本次接口不能单独证明，只能作为当前价格点使用。
- 跨平台隔离：适配器只允许 `yyypSellPrice` 进入领域模型。
- 指标隔离：所有非 `lowest_listing` 价格字段即使出现在响应中也会被直接丢弃。
- 回补能力：未验证，不插值、不补造数据。

## 第一版可承诺

- 使用普通注册用户 Token 按标准 `marketHashName` 批量查询。
- 单批最多 50 个对象。
- 获取当前悠悠最低在售价，并明确记录为 YYYP、CNY、`lowest_listing`。
- 区分成功返回与当前无悠悠有效挂单。
- 覆盖武器箱、刀和手套的当前价格对象。
- 严格丢弃 Steam 和其他平台字段。

## 第一版不可承诺

- 任意历史起点、固定历史粒度或指定区间回补。
- 企业接口、全量目录和高频批量能力。
- 将本地抓取时间解释为平台报价生成时间。
- 将外部平台价格混入悠悠主价格序列。

## 明确排除

- 全项目唯一允许的价格指标是最低在售价 `lowest_listing`。
- 其他价格指标不查询、不保存、不导入、不计算、不通过接口返回，也不在页面展示。
