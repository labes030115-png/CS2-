# 给 Codex 的第一条任务

你正在一个新仓库中开发“CS2 收藏品价格研究看板”。

先不要直接制作完整首页，也不要伪造任何生产数据。请严格执行以下步骤：

1. 阅读仓库根目录 `AGENTS.md` 和 `docs/` 下全部规范。
2. 输出你对产品范围、数据边界、隐私约束和不可做事项的简要理解。
3. 检查推荐技术栈在 Windows 本地运行、SQLite、托盘服务和 PyInstaller 打包方面是否可行。
4. 创建最小项目骨架，但只做到能运行健康检查和测试：
   - `backend/`
   - `frontend/`
   - `desktop/`
   - `tests/`
   - `scripts/`
   - `research/samples/`
5. 实现数据源适配器接口，不接入真实Token：
   - current price
   - historical points
   - item catalog
   - source health
6. 实现假数据适配器和单元测试，用于证明：
   - 悠悠主价格与外部参考价严格分离；
   - Steam 数据会被拒绝；
   - 缺失采样不会被插值；
   - 同一收藏品可多分类展示但价格对象不重复。
7. 创建 SQLite 初始迁移，只包含第一个里程碑需要的核心表。
8. 添加一条命令启动后端健康检查，添加一条命令运行全部测试。
9. 创建 `research/DATA_SOURCE_CAPABILITY_REPORT.md` 模板，但不要声称任何真实API已经可用。
10. 更新 `README.md`，用非程序员能理解的方式说明如何运行当前骨架。
11. 运行测试并报告结果。

本次任务的完成定义：

- 项目能在 Windows 开发环境中安装依赖；
- 后端健康检查通过；
- 数据源适配器契约有测试；
- Steam 拒绝规则有测试；
- 数据缺口规则有测试；
- 未实现完整网页；
- 未调用真实API；
- 未提交任何密钥。

完成后停止，等待下一条里程碑任务。
