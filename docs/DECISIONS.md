# 已确认决策

## 数据口径

- 主价格：悠悠最低在售价。
- 全项目唯一允许的价格指标：最低在售价 `lowest_listing`。
- 所有主来源、外部来源、导入文件、数据库、接口、页面和计算都只处理最低在售价。
- 主K线：悠悠最低在售价OHLC。
- 不使用成交价计算主K线、历史高低点或回撤。
- 不计算平台手续费。
- 名称以悠悠为准。
- Steam价格永久禁用。

## 外部历史

- 悠悠始终为主线。
- 2021年前或悠悠缺失时，可使用 BUFF、C5、IGXE、5E 和经审核旧平台。
- 外部数据必须单独成线，不能与悠悠拼接。
- 必须显示平台、币种、口径、粒度和完整度。
- 首页优先悠悠；悠悠没有有效价格时允许外部补充，但必须醒目标注来源。
- 跨平台高低点和回撤不得混算。
- 外部补充价必须标明真实平台，且不得用于计算悠悠主线指标。
- 无可靠价格时留空，只展示历史事件。

## 采集与显示

- 每15分钟采集。
- 首页每小时刷新。
- 关机或休眠造成、且无法补回的缺口留空。
- 一根事件竖线可以承载同日多个事件。
- 公告日和生效日分别记录、分别画线。
- 全部时间页面显示北京时间；数据库存UTC。
- 日线按北京时间自然日。
- 周线从周一开始。

## 范围

- 所有收藏品和武器箱进入目录研究。
- 首页重点展示存在隐秘级枪皮的系列。
- 枪皮只看普通、非纪念品、非StatTrak、崭新和略磨。
- 武器箱本身需要价格K线。
- 刀和手套跟随对应武器箱。
- 刀和手套只看崭新和略磨。
- 每种刀型和每种手套型号动态展示最贵两个标准涂装。
- 不考虑宝石、模板、浮点、贴纸和人工溢价。
- 同一资产属于多个来源或箱子时，数据只保存一份，页面可以重复出现。
- 收藏品来源标签必须醒目。
- 需要同武器比较页面。

## 本地应用

- Windows。
- 双击桌面图标启动。
- 仅本机访问。
- 托盘常驻。
- 关闭浏览器或控制窗口不停止服务。
- 不使用付费服务器和数据库。
- Token本地加密保存。
- 需要人工修正页面。
- 第一版不真正发送邮件或Discord通知。
- 验证版使用一个刀箱和一个手套箱。

## 存储

- 15分钟原始快照保存90天。
- 小时OHLC保存2年。
- 日OHLC永久保存。
- 事件和外部历史永久保存。
- 4小时和周线动态生成。
- 自动备份总量上限2GB。
