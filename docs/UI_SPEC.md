# UI规范

## 1. 总体

- 中文界面。
- 电脑端优先。
- 高信息密度，但来源和缺失状态必须清晰。
- 不模仿交易平台下单界面；这是研究看板。
- 收藏品和来源标签是首要视觉层级。

## 2. 首页

建议布局：

```text
顶部状态栏
├── 数据更新时间
├── 采集服务状态
├── 待补缺口数量
├── 数据库大小
└── 立即同步

左侧/主区域：收藏品来源树
右侧：价格与指标表
```

每个来源大类：

- 大号标题
- 醒目说明
- 获取机制说明
- 可折叠
- 记住展开状态

示例：

```text
CS2武库收藏品
【武库通行证点数兑换】【不需要钥匙】

蔓藤纹
AK-47丨精灵之噬（蔓藤纹）  崭新
AK-47丨精灵之噬（蔓藤纹）  略磨
AWP丨无上之焰（蔓藤纹）    崭新
AWP丨无上之焰（蔓藤纹）    略磨
```

## 3. 价格单元格

悠悠有价：

```text
¥12,345
悠悠最低在售价
14:15更新
```

悠悠暂时无价、外部补充：

```text
¥12,600
C5补充价格
悠悠当前无有效挂单
14:12更新
```

禁止仅通过颜色表示来源，必须有文字。

## 4. 数据完整度

- 完整：正常图标和文字
- 部分缺失：显示样本数
- 大段缺失：显示缺失区间
- 外部参考：显示平台徽标
- 不可信或待审核：不进入主表，只在管理页显示

## 5. 详情页

顶部：

- 名称
- 收藏品
- 来源标签
- 磨损
- 当前价格
- 当前来源
- 更新时间

图表：

- 1小时 / 4小时 / 日 / 周
- 主蜡烛：悠悠
- 外部参考线：独立开关
- 事件线：可按类型开关
- 缺失区间：不连线
- 鼠标提示展示OHLC、样本数、完整度和来源

事件线：

- 公告日和生效日分别显示
- 同日多事件合并
- 标签位于竖线顶部右侧
- 点击打开侧边栏

## 6. 同武器比较页

- 武器类型选择
- 磨损选择
- 收藏品来源筛选
- 供应状态筛选
- 当前价、回撤、7/30/90日变化
- 归一化走势
- 支持收藏品分组对比

## 7. 武器箱详情

- 武器箱K线
- 当前供应状态
- 状态时间线
- 箱内隐秘级
- 刀/手套池
- 事件影响表
- 公告与生效日期
- 事件前后变化

## 8. 管理页

- 分类编辑
- 拖动排序
- 标签强调级别
- 收藏品多分类归属
- 事件编辑
- 来源审核
- 名称映射
- 人工覆盖历史
- 数据缺口
- 数据源健康
- 备份恢复
