# 可配置或待实测事项

这些问题不阻塞骨架和能力探测，但在正式全量导入前必须确认。

## 1. 刀具和手套涂装排名的代表磨损

已确定只看崭新和略磨，但“一个涂装用哪个磨损参加前二排名”仍可配置。

原型默认：

- 优先使用崭新当前最低在售价。
- 崭新无有效价格时使用略磨。
- 首页仍展示入选涂装的崭新和略磨两行。

管理页应允许改为：

- 略磨优先
- 两个磨损中的较低价
- 两个磨损分别排名

## 2. 外部补充平台优先级

默认：

1. BUFF
2. C5
3. IGXE
4. 5E
5. 已批准旧平台

管理页允许调整，但Steam不可加入。

## 3. 数据源实际能力

必须用用户Token实测：

- 普通权限可取得的历史范围
- 是否能回补关机区间
- 刀、手套和武器箱覆盖率
- 每个接口的稳定频率

价格能力探测只验证最低在售价，不验证其他价格指标。

## 4. 验证用武器箱

研究阶段选择：

- 一个刀具池关系清晰的武器箱
- 一个手套池关系清晰的武器箱

选择后写入研究报告并说明原因。
