# 数据源与价格口径政策

## 1. 允许来源

主来源：

- YYYP / 悠悠有品数据，日常可通过经用户授权且符合条款的数据接口读取。

外部参考来源白名单：

- BUFF
- C5
- IGXE
- 5E
- 经人工审批的旧第三方平台原始文件

禁止来源：

- Steam市场
- 使用Steam价格换算得到的人民币数据
- 无法说明出处、币种、口径和日期的数据
- 需要绕过验证码、风控、登录或访问控制的数据

## 2. 主价格

首页和主K线优先使用悠悠最低在售价。

悠悠最高求购价：

- 可以展示。
- 不参与主K线。
- 不参与主历史最高、最低和回撤。
- 不与最低在售价混合。

## 3. 悠悠缺价

区分两种情况：

### 暂时无有效挂单

展示：

- 悠悠最近有效价及时间
- 当前状态
- 外部补充价格
- 外部平台和更新时间

### 从未取得悠悠价格

展示：

- 当前外部参考价
- 明确来源
- “悠悠暂无价格记录”

不得把外部价格显示成悠悠价格。

## 4. 外部参考线

- 每个平台独立。
- 不与悠悠线拼接。
- 不跨平台计算悠悠回撤。
- 必须记录币种、口径、粒度、起止日期、完整度和导入来源。
- 默认详情页可单独开关。
- 首页在悠悠无价时可显示一个补充参考价，但必须醒目标注。

默认补充优先级建议作为可配置值：

1. BUFF
2. C5
3. IGXE
4. 5E
5. 经批准旧平台

## 5. 历史数据等级

- A：官方或平台开放接口，字段和时间明确
- B：可靠第三方接口或原始导出
- C：可验证的历史文件，来源链完整
- D：社区截图或二手整理，只能作为研究线索
- X：无法验证，不导入价格库

事件资料可引用D级线索帮助检索，但最终事件日期应尽量由A/B级资料确认。

## 6. 数据缺口

- 不插值。
- 不自动连线跨过缺口。
- K线保存实际样本数和预期样本数。
- 不完整K线明确标记。
- 若只有日级点，不生成伪造小时OHLC。
- 若一个小时只有一个点，可显示价格点，但不能宣称该点包含真实小时高低价。

## 7. 数据能力探测

第一阶段必须对用户实际可用的接口进行测试，输出：

- 是否需要Token
- 是否需要IP白名单
- 当前价格字段
- 最高求购字段
- 历史数据最早日期
- 历史返回粒度
- 是否可按时间范围回补
- 单次请求上限
- 频率限制
- 错误码
- 武器箱、刀、手套是否覆盖
- 名称与悠悠映射质量

报告不得把文档示例当作真实可用能力，必须有实际脱敏样例。
