# 验收标准

## A. 数据源隔离

1. 所有平台只有 `lowest_listing` 能进入价格领域模型和数据库。
2. 上游响应即使包含已取消的旧设计指标 `highest_buy_order` 或其他非支持价格字段，也不会进入领域模型、数据库、接口或页面。
3. BUFF/C5/IGXE/5E不会写入悠悠主序列。
4. Steam标识的数据会在导入层被拒绝。
5. 外部价格显示时有平台和币种。
6. 跨平台不计算悠悠回撤。
7. 直接写入已取消的旧设计指标 `highest_buy_order` 会被领域验证和数据库约束拒绝。
8. 导入文件中的已取消旧设计列 `highest_buy_order` 会被忽略，并记录“已忽略非支持指标”。
9. 价格API和页面不返回或展示非最低在售价字段。

## B. 缺口与K线

1. 15分钟数据可正确聚合1小时OHLC。
2. 缺一个样本时 `is_complete=false`。
3. 缺失区间不插值。
4. 图表不跨缺口连续绘制。
5. 单个点不被声明为具有真实高低价的完整K线。
6. 4小时和周线从已保存周期动态生成。
7. 日线按北京时间自然日。

## C. 分类

1. 同一收藏品可属于至少两个来源分类。
2. 首页两处均可展示该收藏品。
3. 两处价格引用同一资产ID。
4. 来源标签字号和视觉优先级达到规范。
5. 展开状态刷新页面后仍保留。
6. 人工排序覆盖不破坏原始导入。

## D. 枪皮

1. 只显示普通、非纪念品、非StatTrak。
2. 只显示崭新和略磨。
3. 同一皮肤两种磨损相邻。
4. 同一收藏品多个隐秘级皮肤按设定顺序相邻。
5. 名称优先悠悠名称。
6. 名称后显示收藏品出处。

## E. 刀和手套

1. 跟随武器箱展开。
2. 同一资产属于多个箱子时数据库不重复。
3. 只显示崭新和略磨。
4. 宝石、模板和特殊溢价对象被排除。
5. 每种刀型动态选最贵两个涂装。
6. 每种手套型号动态选最贵两个配色。
7. 排名改变后自动替换。
8. 被替换对象的历史数据仍可查询。

## F. 武器箱

1. 武器箱有独立价格对象和K线。
2. 状态显示真实描述，不统一写“下架”。
3. 公告日和生效日可分别创建事件线。
4. 事件前后24小时、7、30、90日指标可计算。
5. 箱内隐秘级和特殊稀有池关系可浏览。

## G. 桌面运行

1. 双击图标后启动本地服务。
2. 服务只监听127.0.0.1。
3. 浏览器自动打开。
4. 关闭浏览器后采集继续。
5. 托盘“退出服务”后采集停止。
6. Token不出现在日志、前端或配置明文。
7. 无网络时仍能浏览已有数据。
8. 恢复网络后执行缺口分析。

## H. 存储与备份

1. 90天前15分钟记录可安全压缩或删除。
2. 小时线保留2年。
3. 日线永久。
4. 自动备份不超过2GB。
5. 备份可通过自动测试恢复到临时数据库。
6. 数据库大小和备份大小可在设置页查看。

## I. 非程序员体验

1. 首次启动有中文设置向导。
2. API错误给出中文修复步骤。
3. 不要求日常使用命令行。
4. 有“立即同步”和“查看缺失数据”。
5. 有一键导出脱敏诊断包。
